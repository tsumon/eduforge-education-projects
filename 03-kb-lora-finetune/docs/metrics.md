# 独立规则评估的定义与限制

评估脚本不调用模型，预测必须覆盖测试集全部 ID 且每条恰好一次；`output` 必须是原始模型输出字符串。评分按样例计算后做宏平均，并按五类能力分别汇总。无效 JSON 的全部指标为 0；支持去除最外层标准 JSON 代码围栏。

主要结果使用独立分母：`outcomes.answerable_only` 只含 8 个可回答样例，给出引用编号精确/召回率；`outcomes.refusal_only.strict_success` 只含 6 个必须拒答样例，给出严格拒答成功率。没有该类样例时返回 null，避免把无样例当作成功。下面的旧宏平均仍保留用于诊断，不能替代子集结果。

- **JSON 有效率**：对象中 `answer`、`missing_information` 为字符串，`citations` 为字符串数组，`refused` 为布尔值。它不检验事实正确性。
- **引用编号精确率**：预测的唯一编号中，同时属于人工参考编号和当前可用资料编号的比例。预测空、参考也空时记 1；预测空但参考非空时记 0。
- **引用编号召回率**：人工参考唯一编号中，预测且存在于资料中的比例。参考空、预测也空时记 1；参考空但预测非空时记 0。因此总体分数包含拒答的空引用配对，需同时看可回答任务的分能力结果。
- **关键词召回率**：人工 `keywords` 中逐字（不区分大小写）出现在回答里的比例。没有关键词的样例使用拒答信号符合值作为保守占位；该字段不是语义忠实率，尤其不能单独解释无关键词的术语样例。
- **拒答信号符合率**：可回答样例要求 `refused=false`。拒答样例要求 `refused=true`、`missing_information` 非空、无引用，并在答案中含预先定义的「不足 / 无法 / 矛盾 / 不能确定」之一。这是固定措辞代理，可能漏判“需要更多信息”等合理表达，也可能误收带这些词但仍有编造的回答。正式评价必须人工复核；本次没有根据测试输出调整此规则。
- **答案字符 F1**：移除空白后，按字符计数的多重集合重合度 F1。它不检查词序、推理、条件关系或含义。

上述指标用于暴露格式与引用问题，不能证明每个事实得到证据支撑。特别要检查：引用为空却给出事实、混用冲突日期、遗漏适用条件、拒答只写“无”而没有可操作的补充材料方向。

同一 14 条 held-out 测试已在 pilot 中被开发者查看，后续固定 100 步轮次没有据此调学习率、rank、数据划分或修预测，但它仍不是完全未见的最终盲测。真实教育场景验收需要新增独立来源和人工标注测试。
