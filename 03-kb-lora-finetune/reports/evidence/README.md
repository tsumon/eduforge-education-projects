# 历史合成实验的报告证据

此目录保存原实验的训练清单、日志、独立评估、基线与 adapter 原始预测副本。预测文件只有样例 ID 与原始模型输出，不包含训练集，也不是学校采集的业务问答。

原实验来源为 12 份 AI 编写的合成教育材料，共 84 条模板样例，按文档组划分为 56/14/14。各集合共享模板，拒答题包含情境标记，pilot 阶段已查看测试输出，因此不能把结果当作盲测或真实业务准确率。

`formal/qwen-run1` 为固定基座版本的真实 100 步运行；`qwen-pilot` 和 `verified-smoke` 等目录保留较早运行的结果。随机微型模型仅验证训练流程，没有可用教育语言能力。

原始预测、训练指标和 SHA256 证据保留原样。模型权重、分词器与训练数据不在公开仓库中；完整性清单里存在权重摘要不表示仓库包含权重。
