# 《高等数学 A》第 2 章 极限与连续 讲义

> 本文为 EduForge 合成演示资料，内容为教学用途的概括整理。

## 数列极限与函数极限

数列极限采用 ε-N 定义：对任意正数 ε，存在正整数 N，当 n 大于 N 时恒有 |a_n − A| 小于 ε，则称数列收敛于 A。函数极限采用 ε-δ 定义：对任意正数 ε，存在正数 δ，当 0 小于 |x − x0| 小于 δ 时恒有 |f(x) − A| 小于 ε。极限若存在则唯一，收敛数列必有界。

## 极限的四则运算法则

若 lim f(x) 与 lim g(x) 都存在，则和、差、积的极限等于极限的和、差、积；商的极限等于极限的商，但要求分母极限不为零。使用四则运算法则的前提是参与运算的每个极限都存在，这是学生最容易忽略的条件。

## 两个重要极限

第一个重要极限：当 x 趋于 0 时，sin x 除以 x 的极限等于 1。第二个重要极限：当 x 趋于无穷时，(1 + 1/x) 的 x 次方的极限等于 e；等价形式为当 t 趋于 0 时，(1 + t) 的 1/t 次方的极限等于 e。

## 无穷小的比较与等价无穷小

设 α、β 为同一过程下的无穷小，若 β/α 的极限为 0，称 β 是 α 的高阶无穷小；若极限为非零常数，称同阶无穷小；若极限为 1，称等价无穷小。当 x 趋于 0 时的常用等价无穷小：sin x ~ x，tan x ~ x，1 − cos x ~ x²/2，ln(1 + x) ~ x，e^x − 1 ~ x，(1 + x)^a − 1 ~ ax。等价无穷小替换只能用于乘除因子，不能直接用于加减项。

## 函数的连续性与间断点

函数 f 在点 x0 连续，是指 f 在 x0 有定义、极限存在且极限值等于函数值。间断点分为两类：第一类间断点左右极限都存在，其中左右极限相等的称为可去间断点，不相等的称为跳跃间断点；第二类间断点至少有一侧极限不存在，常见的有无穷间断点和振荡间断点。

## 闭区间上连续函数的性质

闭区间上的连续函数具有有界性定理、最大值最小值定理、介值定理和零点定理。零点定理：若 f 在 [a, b] 上连续且 f(a) 与 f(b) 异号，则在 (a, b) 内至少存在一点使 f 等于 0。洛必达法则属于导数应用，将在第 3 章讲授。
