# 《Python 程序设计》第 5 讲 函数与作用域 讲义

> 本文为 EduForge 合成演示资料，内容为教学用途的概括整理。

## 函数的定义与调用

函数使用 def 关键字定义，函数名后的括号内列出形式参数（形参），调用时传入的值称为实际参数（实参）。函数体必须缩进。没有 return 语句或 return 后不带表达式的函数，调用结果为 None。函数可以通过 return 同时返回多个值，本质上是返回一个元组。

## 参数传递

Python 支持位置参数、关键字参数、默认参数、可变位置参数 *args 与可变关键字参数 **kwargs。默认参数的默认值只在函数定义时求值一次，因此不要用可变对象（如空列表 []）作为默认值，否则多次调用会共享同一个列表，这是初学者最常见的陷阱之一。推荐写法是默认值设为 None，在函数体内判断后再创建新列表。

## 作用域规则 LEGB

Python 查找变量名时按 LEGB 顺序进行：Local（当前函数局部作用域）、Enclosing（外层嵌套函数作用域）、Global（模块全局作用域）、Built-in（内置作用域）。在函数内部对一个名字赋值，默认会创建局部变量；若要修改全局变量必须使用 global 声明，若要修改外层函数的变量必须使用 nonlocal 声明。

## 常见错误 UnboundLocalError

如果函数内既读取又赋值同一个全局名字而没有 global 声明，Python 会把它当作局部变量，于是在赋值之前读取就会抛出 UnboundLocalError。解决办法是加 global 声明，或改为通过参数传入、返回值传出。

## 递归

递归函数必须包含基线条件（终止条件），否则会无限调用。Python 解释器默认的最大递归深度为 1000 层，超过会抛出 RecursionError；可用 sys.setrecursionlimit 调整，但不建议依赖它，深层递归应改写为循环。课堂示例包括阶乘、斐波那契数列和判断回文字符串。
