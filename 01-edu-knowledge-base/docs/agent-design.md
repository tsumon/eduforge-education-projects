# 知识库 Agent

`app/agent_runtime.py` 使用真实 LangGraph `StateGraph`。节点为 model、tools、validate，通过条件边形成循环。模型回复 `tool_calls` 时，程序校验参数并执行白名单工具，将对应 `tool_call_id` 的观察送回模型；最终正文通过独立核验才接受。核验失败会在剩余预算内返回模型修正。

知识库工具：

| 工具 | 作用 |
|---|---|
| search_knowledge | Embedding/Qdrant 与 BM25 召回和筛选，可改写查询后重试 |
| read_evidence | 只读取本次搜索得到的编号，返回可引用的完整分片 |
| check_answer | 检查草稿是否满足已读取引用和数字约束 |

每次运行的候选与已读取集合独立。最终答案必须先有成功搜索，引用编号必须实际读取；每段有引文且数字来自所引原文。拒答文字由程序收束，防止用拒答前缀夹带未核验事实。读取及保存时核对 SQLite 资料，避免中途删除后继续引用。

模型 API 异常、损坏协议、未知工具、非法参数都有明确记录。工具错误可供模型调整；模型调用失败终止。默认最多 8 次模型决策、12 次工具调用，每次模型最多请求 4 个工具，每个工具参数最多 8,000 字符、观察最多 20,000 字符。无任意文件、shell、浏览器或报告写入工具。LangSmith 自动遥测在图调用上下文中关闭。

历史保存完整运行快照，不保存隐藏思考过程、API Key、提供商地址、请求头或原始错误正文。`completed` 表示程序约束通过，仍可能是有记录的拒答；`failed`、`limited`、`not_configured` 不会被替换成成功的 Agent 答案。基础 RAG 调试模式单独保留旧的生成/抽取行为。

图运行期间不持有业务门面的整段锁；工具只在检索或读写数据库时短暂持锁，避免 LangGraph 工作线程死锁。状态在运行完成后写入 SQLite，当前未实现进程中断后的节点续跑。

`app/agent_runtime.py` 在两个可独立打包的 Web 项目中保持字节一致。它不导入兄弟项目。校验只能检查程序约束，不能证明全部自然语言推论正确。测试采用本机脚本提供商，不代表真实模型质量。
