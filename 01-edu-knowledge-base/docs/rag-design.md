# API 版 RAG 设计

本轮范围为代码、配置示例、测试和文档。Embedding 与回答模型均通过 OpenAI 兼容 HTTP API 调用，不下载或加载本地模型；向量数据库为本地持久化 Qdrant，BM25 保留用于精确词检索。

资料按标题/段落/完整句切分，过长单句也受长度上限约束。Embedding 分批请求并校验响应数量、索引、维度、有限数值和非零范数，按输入顺序恢复并归一化。接口地址、模型名、预期维度、版本及查询前缀参与模型签名，API Key 不参与签名、不进入状态响应。

SQLite 是资料与历史的唯一事实来源。Qdrant 点使用分片 ID 的稳定 UUID，保存内容摘要和模型签名。启动及资料变更时对账，复用未变向量；强制重建可重新编码所有分片。模型计算完成后才修改向量数据，失败保留旧点并将服务标为不可用。跨 SQLite/Qdrant 的更新不是分布式事务，已提交资料可在修复接口后重建恢复。

查询同时进行向量和 BM25 召回，使用排名融合；语义门槛独立于 BM25，精确词法证据优先，同义问法可走纯语义证据。陌生英文实体不会被替换成库中不同主体。模型每段必须有合法引用，数字必须出现在所引原文中。生成失败只在已有精确证据时允许原句抽取，否则拒答；检索失败返回 503。校验不能证明语义蕴含，也不支持任意计算推导的新数字。

配置从 `.env` 或环境变量读取，缺少完整 RAG 配置会明确提示。轻量模式须显式选择 `--profile lexical`。状态只返回模型名、维度、版本、就绪状态和数量，不返回凭证或提供商地址。

验证采用不加载模型的测试：本机 HTTP 测试提供商 + 真实 Qdrant + FastAPI 全链路，检查 HTTP 请求、独立密钥、响应乱序/损坏、引用、降级、同步和重启。真实提供商未配置，不能声称已完成真实模型联调或质量验收。历史截图不作为本轮 API 联调证据。
