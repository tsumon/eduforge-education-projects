# 教育 Agent 改造范围

两个应用使用 LangGraph 的 model → tools → model 循环。模型通过可配置的 OpenAI 兼容 API 决定工具和参数；不下载权重。原有检索、评分和统计成为可测试的确定性工具，不能仅更名为 Agent。

- 知识库：动态检索、读原文、校验引用；允许改写查询。答案仅使用实际读取且仍存在的证据，失败或超限明确停止，保留工具记录。
- 学情诊断：模型查询班级统计、评分与进度、知识点或个人证据、题库参考，生成有依据的补讲和分层练习。分数不由模型计算，生成内容待教师复核。
- 每次运行隔离工具和证据，限定步数、调用数、参数大小和观察长度；不提供文件、网络搜索、命令执行或任意报告读写工具。
- 前端显示 Agent 状态、建议和工具记录；未配置模型时明确显示基础统计预览。
- SQLite 保存运行快照；新建议不能继承旧建议的复核状态。

验收采用本地 HTTP 假提供商执行真实 LangGraph、真实领域工具、SQLite 和 Qdrant 链路，覆盖工具调用、调整、核验修复、拒答、异常、越权、超限、持久化和鉴权。此验证不代表真实模型质量或真实提供商已联调。

两个项目独立交付，`app/agent_runtime.py` 保持逐字相同，避免跨项目目录依赖。修改后回归测试、隐私扫描、同步原始代码并推送已有公开仓库。第三个 LoRA 实验保持原有结果。
