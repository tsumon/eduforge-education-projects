# Local typefaces

Geist Regular / Medium / Bold and Geist Mono Regular are served from this directory, with no runtime request to a third party.

Source: Google Fonts, https://fonts.google.com/specimen/Geist and https://fonts.google.com/specimen/Geist+Mono .

Font authors: The Geist Project Authors. License: SIL Open Font License 1.1; full text in `LICENSE`.

The interface uses Geist for Latin text and the operating system's Chinese sans-serif glyphs. Geist Mono is used only for literal code and diagnostic JSON.
