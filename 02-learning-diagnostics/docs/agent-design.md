# 学情诊断 Agent

LangGraph 的 model → tools → model 循环由模型的真实 `tool_calls` 驱动；model → validate 接受最终方案或返回修正反馈。模型不是固定统计流水线的装饰性总结器，它选择调查对象、工具、参数和后续行动。统计计算和评分阈值是领域工具，模型不能改写统计。

| 工具 | 作用 |
|---|---|
| get_class_summary | 本次班级汇总、有限知识点目录与基础层学号 |
| get_rubric_and_progress | 本报告生成时的评分标准、课程进度、缺失处理口径 |
| list_topics / list_students | 当前报告内分页目录 |
| inspect_topic | 指定知识点统计、显式错因和最多五条失分证据样本 |
| inspect_student | 指定学号的个人统计和有限知识点证据，可传 topic 缩小范围 |
| get_exercise_examples | 按知识点和层级读取合成参考题库 |
| validate_plan | 可选方案自检，不能跳过服务端最终核验 |

所有工具绑定一个不可变报告快照，不接受任意报告 ID，不提供删除、复核、文件、shell 或任意网络访问工具。每次运行使用独立证据注册表；只有实际返回的证据编号才能被引用。

最终 JSON 包含 summary/summary_evidence_ids、findings、reteaching、exercises、missing_data。班级汇总和评分进度必读；诊断性 findings 仅允许 assessed 知识点，未评估信息只能作为缺失/范围说明。知识点结论要引用该知识点的 inspect_topic，个人结论还要有相同学号、相同知识点的 inspect_student。学情描述中的数字须来自引用工具数据；未授课、进度外和数据不足不能安排补讲或练习。新练习允许新题目数字，附提示和参考答案，并标记 `origin=model_generated`、待教师复核。

数字检查只能确认数值出现在引用证据中，不能证明所有语义、错因、建议或参考答案正确；自然语言、题目和教学适配仍需教师审查。工具观察是有限样本，不能冒充已逐人调查全班。模型最终回复受 4,096 输出 token 及 12,000 字符协议上限约束，复杂需求应拆成多次目标明确的运行。

默认 8 次模型决策、12 次工具调用，单次最多 4 个工具；参数和观察有长度限制。工具失败可调整调用，最终不通过或超限则停止；未配置、失败和超限只有基础统计预览，不发布假 Agent 方案。

SQLite `reports` 保留确定性快照，新增 `agent_runs` 保存每次运行完成后的目标、状态、建议和工具记录。没有写入节点级持久化检查点，不支持进程中断续跑。生成方案与复核分别处理，新运行重置待复核；复核必须匹配当前运行 ID，检查与更新在同一锁和事务内进行。报告与最新运行以一条 SQLite 查询读取，避免并发更新时组合出错误复核状态。

模型通过你配置的 OpenAI 兼容 API 调用，须支持 tools/tool_calls。工具观察发送给提供商，姓名字段不主动发送，备注仍可能含个人信息。密钥、地址、请求头和原始提供商错误不写入报告。LangSmith 自动遥测在图调用时关闭。两个 Web 项目的 `app/agent_runtime.py` 保持字节相同，均可独立运行和交付。
